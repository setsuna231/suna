# Security Policy

## Supported Versions

Currently, only the latest major/minor version is supported.

| Version | Supported          |
| ------- | ------------------ |
| 0.8.x   | :white_check_mark: |
| < 0.8   | :x:                |

## Reporting a Vulnerability

If you find a vulnerability (e.g., a bug that allows `suna` to delete files outside its intended scope, or a buffer overflow), please do **not** open a public issue.

Instead, contact me directly at vedhashiva231@gmail.com. I will try to respond within 48 hours and patch it immediately.
